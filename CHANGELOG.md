# Project Changelog

All notable changes to this project are documented here.

### v1.0.1
- Initial release of landing page order form.
- Basic database migrations.

### v1.0.2
- Added district and upazila dropdown selector.
- Configured standard delivery charges.

### v1.0.3
- Integrated Steadfast Courier API for parcel booking.
- Added tracking code fields in order model.

### v1.0.4
- Added fraud detection modal in admin order view.
- Implemented IP blacklist filter.

### v1.0.5
- Improved mobile responsive checkout layout.
- Optimized image loading with WebP format.

### v1.0.6
- Added related addons picker in product settings.
- Support for multi-quantity discounts.
