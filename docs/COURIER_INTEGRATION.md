# Courier API Integration Notes

### Supported Logistics Partners
- **Steadfast Courier**: API v1 integration for consignment creation and status polling.
- **Pathao Courier**: Token-based REST API for parcel delivery and tracking webhooks.

### Configuration Parameters
- `api_key`: Logistics API authentication key.
- `secret_key`: Courier partner secret token.
- `webhook_url`: Notification endpoint for delivery status callbacks.
