# Payment System & Settlement

### Payment Types
- **COD (Cash on Delivery)**: Primary checkout option for Bangladesh retail e-commerce.
- **Advance Delivery Charge**: Optional partial payment gateway for fraud mitigation.
- **Payment Verification**: Auto-reconciliation of courier collected funds vs recorded totals.
